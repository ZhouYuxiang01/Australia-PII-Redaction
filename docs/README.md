# Customer Handover Package

This directory contains the customer-facing handover documents for deliverable
review and sign-off.

## Core Documents

| Document | Purpose |
|---|---|
| [DELIVERABLES.md](DELIVERABLES.md) | Maps D1-D4 customer requirements to repository evidence. |
| [MODEL_CARD.md](MODEL_CARD.md) | Describes the trained hybrid model, intended use, training data, metrics, limitations, and licence notes. |
| [EVALUATION_REPORT.md](EVALUATION_REPORT.md) | Provides evaluation methodology, datasets, quantitative results, robustness notes, and success criteria confirmation. |
| [ARTIFACT_MANIFEST.md](ARTIFACT_MANIFEST.md) | Lists model artifacts, sizes, checksums, paths, and loading instructions. |
| [DEPLOYMENT.md](DEPLOYMENT.md) | Covers local/Docker launch, environment variables, health checks, smoke tests, and operations notes. |

## Supporting Materials

| Material | Location | Notes |
|---|---|---|
| API documentation | [../API.md](../API.md) | Customer-facing HTTP API reference. |
| Final report | [../FinalReport.pdf](../FinalReport.pdf) | Project report / narrative summary. |
| Presentation | [../Presentation.pdf](../Presentation.pdf) | Presentation deck for project/demo review. |
| FastAPI OpenAPI docs | `/docs` on a running service | Interactive endpoint documentation generated by FastAPI. |

The PDF files are kept at the repository root to avoid breaking existing links
or submission paths. This index includes them as part of the handover package.
